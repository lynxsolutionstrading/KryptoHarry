# Kryptoharry Landing Page

German-language landing page for Krypto Harry — Bitcoin mining consulting.
Single-page conversion funnel that drives traffic to a Telegram 1:1 chat.

**Stack:** Vite+ (VoidZero unified toolchain) + Vite 7 + React 19 + TypeScript + plain CSS Modules.
**Hosting:** Vercel.

---

## Quick start

```bash
pnpm install
pnpm dev            # http://localhost:5173
```

## Scripts

| Command              | What it does                                                  |
| -------------------- | ------------------------------------------------------------- |
| `pnpm dev`           | Start dev server with HMR (`vp dev`).                         |
| `pnpm build`         | Type-check (`tsc -b`) then production build (`vp build`).     |
| `pnpm preview`       | Preview the built `dist/` output locally.                     |
| `pnpm check`         | Format + lint + typecheck in one pass (`vp check`).           |
| `pnpm lint`          | Lint only.                                                    |
| `pnpm fmt`           | Format only.                                                  |
| `pnpm optimize-logo` | Regenerate logo WebP/AVIF/PNG variants from `design-source/`. |

## Environment variables

Copy into `.env.local` for dev. Never commit these.

| Variable                 | Purpose                                                               | Default                    |
| ------------------------ | --------------------------------------------------------------------- | -------------------------- |
| `VITE_TELEGRAM_URL`      | Telegram deep-link the CTAs point to                                  | `https://t.me/kryptoharry` |
| `VITE_VSL_URL`           | YouTube/Vimeo URL for the hero video (empty = show poster only)       | _(empty)_                  |
| `VITE_ANALYTICS_ENABLED` | Set to `true` in production to load Vercel Analytics + Speed Insights | `false`                    |

## Project structure

```
src/
├── App.tsx               # composes the section components in order
├── main.tsx              # entry, mounts React, loads analytics if flagged
├── assets/               # pre-optimized logos (AVIF/WebP/PNG @ 400 & 800)
├── components/           # one .tsx + .module.css per section
├── hooks/useFadeUp.ts    # shared IntersectionObserver fade-in
├── i18n/
│   ├── index.ts          # t() helper
│   └── locales/de.json   # all page copy lives here
├── lib/
│   ├── config.ts         # env-sourced URLs + flags
│   └── analytics.ts      # conditional Vercel analytics loader
└── styles/               # tokens.css, reset.css, global.css
```

All German copy lives in `src/i18n/locales/de.json`. Adding a second locale is a drop-in
swap to `react-i18next` — no component changes needed.

## Deploy (Vercel)

Vercel auto-detects Vite and reads `vercel.ts` for caching rules. Push the `main`
branch to a connected repo, or run:

```bash
vercel --prod=false   # preview
vercel --prod         # production
```

`vercel.ts` sets `Cache-Control: public, max-age=31536000, immutable` on fingerprinted
assets (`/assets/*`) and static fonts/images — Vercel serves the pre-compressed
Brotli/gzip artifacts generated by `vite-plugin-compression2`.

## Performance budget

First-paint transfer targets (gzipped):

- JS ≤ 80 KB
- CSS ≤ 15 KB
- Logo ≤ 20 KB
- **Total ≤ 150 KB**

Run `pnpm build` and inspect `dist/` to verify.

## Design notes

- **Fonts:** Bebas Neue (display) + DM Sans (body). Self-hosted via `@fontsource*`.
- **Palette:** `#080808` black, layered darks `#111 / #161616 / #1E1E1E`, Bitcoin gold `#C9A84C`.
- **Motion:** One shared IntersectionObserver drives section fade-ups. Respects `prefers-reduced-motion`.
- **Mobile-first:** 80–90 % of traffic is mobile. All grids collapse to one column below 640 px; sticky CTA stays above iOS home indicator via `env(safe-area-inset-bottom)`.
